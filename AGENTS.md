# PersonaSLM — Repository Instructions

## Project

PersonaSLM is an independent NLP empirical research project.

Paper title:
Understanding the Effects of Persona Conditioning on
Dialogue Reliability in Small Language Models.

Research Protocol: v1.1

## Git Policy

The human researcher exclusively manages Git commits
and pushes.

Codex must NOT:

- Execute git commit.
- Execute git push.
- Automatically create commits.
- Modify Git author or committer configuration.
- Add "Co-authored-by: Codex" trailers.
- Add "Generated by Codex" commit metadata.
- Rewrite Git history.
- Force push.

Codex may:

- Inspect git status.
- Inspect git diff.
- Inspect git log.
- Read repository history.
- Prepare code changes.
- Run tests.
- Recommend commit messages.

All source changes must remain uncommitted until
reviewed and committed by the human researcher.

## Reproducibility

Every engineering and experimental change must be
documented.

Maintain:

docs/research_development_log.md

Record:

- Date and time
- Research phase
- Files changed
- Commands executed
- Test results
- Experimental configurations
- Errors and fixes
- Scientific limitations

Record factual development provenance accurately.

Do not fabricate measurements or claim that
unexecuted experiments have been completed.

## Research Boundaries

Maintain Research Protocol v1.1.

Do not access MimooPet.

Do not begin P1 before P0 acceptance.

Do not train LoRA unless explicitly authorized.

The research must remain reproducible.
