## Evidence-based candidate error distinctions

Fifteen identifiable replies select a value belonging to a different target time: eight later-state selections (PC009, PC019, PC031, PC048, PC053, PC065, PC067, PC070) and seven earlier-state selections (PC012, PC016, PC029, PC037, PC049, PC058, PC071). Both factual and temporal Incorrect are proposed. These are observed claim/evidence discrepancies, **not attribution to the historical treatment**. The supplied ledger itself includes several dated values.

For example, PC009 assigns Nora Finch to Laurel on 2042-06-15. Facts `p1c_speaker_06_f04` and `f11` specify route 62 and Cobalt for that requested period. Laurel follows the later route 63 (`f07`, `f12`). PC012 instead selects Silver, the earlier route 61 destination (`f01`, `f10`). Both differ from the same June reference. This supports date-sensitive error descriptions without proving which prompt segment caused them.

Five replies (PC011, PC027, PC030, PC035, PC040) assign Idris Fern to Laurel rather than Silver for June. The trusted target derivation is `p1c_speaker_05_f04` plus `f11`. Laurel appears for **Archive colleague 5**, collection desk, in `f14`, during the same period. Factual Incorrect is proposed; Temporal Unverifiable preserves uncertainty about temporal versus entity/attribute error. The researcher may adjudicate temporal Incorrect if the approved rubric treats every false date-indexed assignment that way; the distinction must remain documented. Surface overlap is not proof of the model's retrieval process.

PC004 supplies the correct destination value Cobalt but calls it a collection desk rather than a room. The proposal accepts the requested referent, with lower relevance/coherence (4) and moderate confidence. A strict attribute interpretation could require Unverifiable/task uncertainty; explicit adjudication is requested.

PC006 supplies both required values Orchid and Thursday, but says “on Thursday, 2042-12-15.” The evidence defines a service-day attribute, not a weekday-of-calendar-date relation. Proposed factual/temporal Unverifiable and unknown task success preserve this ambiguity; component coverage is 1 and completeness YES. Accepting a service-day paraphrase would instead support Correct and task success. No external calendar or changed reference answer was introduced.

The other 42 supported replies have case-specific reference quotations and complete answers. Correct route destinations do not establish that multi-step reasoning occurred; shortcuts and repeated values remain possible. The proposed ordinal ceiling (59 scores of 5 among 64 rated replies) may limit discrimination even when factual judgments vary.
