# P1d publication evidence gaps — v1

Maintainer: Yaxin ZHENG. First submission target: PLOS ONE. Current status: NOT READY FOR SUBMISSION.

PLOS ONE requires original research, technically sound methods and analyses, appropriate conclusions, ethical standards and reporting/data availability. Reproducibility alone is not sufficient; neither a null result nor an algorithm label guarantees acceptance. See the [official publication criteria](https://journals.plos.org/plosone/s/criteria-for-publication).

| Required evidence | Current state | Action before a defensible submission |
| --- | --- | --- |
| Meaningful primary question and identification | P1c package effects unstable; no pure mechanism | Approve a narrower source-selection question or separately identified topical manipulation |
| Measurement validity | AI-assisted adopted labels, boundary sensitivity, shared scoring history | Independent masked review, independent boundary truth, distinct component/delivery coding |
| Independent replication | Development data only | Freeze and execute new bank after approval; no case reuse or sign-directed selection |
| Precision | Six P1c clusters; unknown-outcome bounds | Larger independent allocation with justified precision; report bounds even if inconvenient |
| Generalization | One Base model and synthetic English speakers | Paired model sensitivity and later governed external validation; no real-person fidelity claim |
| Controls | Procedural text not semantically neutral | Independent control review; retain diagnostic-only limits if neutrality fails |
| Prior art and contribution | Direct overlap in steering, admission, retrieval, verification and boundary measurement | State falsifiable incremental empirical contribution; test methods fairly before originality claims |
| Data/code/ethics | Local reproducibility and preserved records | Versioned public-release plan, licenses, de-identification if real data later used, truthful AI-assistance disclosure |

A viable empirical contribution is an independently measured test of entity/time conflict under sufficient evidence, with explicit robustness to boundary and missingness decisions and preserved null results. It is not established by P1c or by current simulations. A stronger algorithmic venue would require a demonstrated methodological gap, strong baselines, ablations, fidelity/cost results and independent validation; no such contribution is claimed now.

## Algorithmic Opportunity Assessment

**Observed Failure Modes:** boundary sensitivity and semantic/delivery discrepancies motivate measurement work. **Existing Methods and Published Prior Art:** [the comparison](P1d_published_baseline_comparison.md) documents substantial overlap. **Potential Algorithmic Improvements:** a selective verifier or boundary abstention method remains a candidate only. **Validation Feasibility:** existing implementations currently solve authored structured fixtures; real-language extraction and independent truth remain unvalidated. **Publication Value:** an honest negative algorithm result does not undermine a well-controlled empirical study. Prioritize independent measurement over adding unreviewed experimental arms.
