For response boundaries, v5 already records native EOG, conventional stops, official templates, grammar-constrained decoding and DCCD. The new diagnostic adds actual generation-time stop evidence to the earlier offline shadows: all eight stop outputs equal the conventional shadow, while complete task answers remain zero. This supports no novel parser claim. Grammar/format validity and semantic answer delivery must remain distinct.

The strongest present research opportunity is a carefully validated measurement/configuration study linked to persona-conditioning experiments. A CPU-efficient evidence-state method remains an unverified candidate only if a reproducible error survives strong simple and published baselines on independent cases. The H_none-only diagnostic cannot establish a history-interference mechanism.
