# Catalogue des rapports

Pour une première lecture, commencer par le [guide](README.md) et les [résultats](resultats.md). Cette page sert surtout à retrouver un document précis.

Les noms et les versions sont conservés tels quels. Une proposition, une revue et un rapport d'exécution décrivent des choses différentes ; ce classement par étape n'indique pas qu'une proposition a été adoptée. Le [journal](research_development_log.md) permet de suivre les décisions.
