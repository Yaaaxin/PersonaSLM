# P1d independence and template audit — v1

Maintainer: Yaxin ZHENG. The current bank is prospective and unfrozen.

There are 144 distinct persona identities and 144 distinct paired other-person identities, 288 distinct evidence texts and no exact question or full-person-name reuse against the inspected P1b/P1c review sources. This supports separation from those observed cases, not independent linguistic sampling. All prior P1d development examples remain excluded from the prospective case IDs and from final empirical analysis.

The census finds **247 distinct question strings** among 288 cases. Twenty-one repeated-question groups contain 62 records (41 repetitions beyond the first). The repetitions are contextual questions whose fixed contexts and ledgers differ; they are not duplicate whole cases. There are only **16 abstract question grammars**, with four common implementation blocks. Each family has template-block counts 18/24/18/12, not equal counts. Across all families, blocks have 72/96/72/48 cases; persona-target counts are 48/48/24/24. Therefore template and target-role heterogeneity are not independently balanced. Forty speakers have both cases in the same domain. Fifty-eight distinct required value strings recur within the bank, from finite code/window pools; a shared value alone is not copied ground truth.

The independent candidate grammar derives from the same service-ledger development tooling. Fresh names, dates and permutations do not fulfill a broad claim of independently authored task templates. This matters because the approved addendum calls for new independent domains/templates. **The materials are suitable for review as new instances of a finite grammar, but are not yet certified as the intended independent-template validation bank.** Resolve the scope explicitly before freezing: either document acceptance of the restricted finite-template target through the required scientific amendment, or construct and independently review new template families without inspecting model outputs. This does not reopen adoption of the existing plan or silently change its estimands.

No candidate output exists and no future validation answer was used to tune algorithm parameters. Algorithm tooling continues to use the separate 2048 development bank and authored fixtures; the candidate bank uses 2054 scenario ledgers. Preserve this separation after freeze.
