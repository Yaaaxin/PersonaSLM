Maintainer: Yaxin ZHENG. Paper: *Understanding the Effects of Persona Conditioning on Dialogue Reliability in Small Language Models*. Target: PLOS ONE. Protocol v1.1 remains formal; v1.2 Revised Proposed r1 is unadopted.

## Current judgment: development evidence, not submission-ready validation

The analysis is reproducible and exposes useful measurement distinctions. It is not an independent confirmatory study. PLOS ONE requires sound methods and statistics, supported conclusions, research integrity and transparent reporting/data availability; negative and null results can be eligible. Acceptance is not guaranteed. [Official publication criteria](https://journals.plos.org/plosone/s/criteria-for-publication).

| Requirement | Current evidence | Remaining limitation or action |

## Annotation reliability

Researcher adoption is valid provenance, not a second independent annotation. Seek a genuinely independent human review of a prospectively selected subset spanning families, complete/partial/no-answer records, contradictions and BR168's ambiguous unit. Keep that reviewer masked to treatment and suggested ratings. Preserve both versions before adjudication. Only actual paired human judgments can support an agreement analysis, with uncertainty and sampling disclosed.

The present 137 Correct labels are response-level judgments about supplied claims, not an atomic-claim inventory. Semantic completeness and component delivery are separate. Inspect implicit dates, true intermediate facts, promises and possibly unsupported additional identity claims when validating the rubric. Do not rewrite the current version silently.

## What the calibration supports

The reviewed bank distinguishes supported claims from complete requested answers and contains temporal contradictions despite supplied evidence. It supports scoped, exploratory paired comparisons and future measurement planning. It does not establish general persona harm, superior task validity merely from increased errors, an isolated H mechanism or an original algorithm.

The observed conditional and null results should all be retained. Independent style realizations, model/template sensitivity and real-speaker generalization remain unresolved. The neutral-control review is separate; no C1-N_style or C3-N_history result is available.

## Publication path

First validate semantic units and labels using existing outputs. Then prospectively freeze an independent mechanism or replication experiment with clear estimands and useful precision. Prepare portable data/code release inventories and truthful disclosure of AI assistance. Keep the optional algorithm track gated by reproducible failures that established baselines do not resolve. Increasing generation count alone does not improve publication readiness.
