# P1 Wave 1 Next-Experiment Decision

Maintainer: Yaxin ZHENG. Target: PLOS ONE. Protocol v1.1 remains the execution authority. This document recommends a decision; it authorizes no inference and does not adopt v1.2 r1.

## Evidence-based recommendation

**Complete semantic measurement first (D). Then consider a separately controlled Instruct feasibility arm (B), conditional on those judgments and researcher authorization. Do not expand the Base pilot now.** A narrow independent format diagnostic (C) is an alternative if the approved question is specifically about response boundaries rather than post-training/configuration robustness.

The [audit](P1_wave1_measurement_audit.md) supports 96 reproducible raw observations and first spans, but only 15/72 conclusive automatic factual labels. The other 57 reflect recognizable dated-answer forms or tasks routed to human review; they are not established factual failures. All factual-task responses are CROSS_TURN, while first-span budget censoring is restricted to nonfactual family C. Semantic review could materially change interpretation without any extra generation. Existing structural simple contrasts hinge on one case. More responses using the same incomplete scoring system would not resolve these measurement limitations.

## Gates for a researcher decision

| Question | Current answer | Minimum next evidence |
|---|---|---|
| A. Can semantic reliability be measured meaningfully? | Potentially, because all 72 factual first spans bind to narrow source forms; validated human coverage remains incomplete | Independent judgments of unit, completeness and applicable endpoints, with unresolved cases retained |
| B. Do structural failures distort condition differences? | Full-continuation scoring/excluding CROSS_TURN would distort eligibility; specific semantic distortion has not yet been measured | Compare separately recorded first-span judgments and continuation notes, without replacing frozen scores |
| C. Is Instruct more informative than Base expansion? | Probably after D, given saturated factual-task CROSS_TURN and concentrated nonfactual censoring | Approve a separately versioned configuration question and independent evaluation material; do not interpret template/post-training jointly changed as a pure mechanism |
| D. Are S/F/H comparisons interpretable? | Yes as operational intervention packages within shared evidence; no as isolated semantic mechanisms | Retain package interpretations, inspect style realization and identity, review P1 controls before matched comparisons |
| E. What helps a PLOS ONE study? | Reliable measurement, a specific justified empirical question, and adequate independent evidence | Specify power/precision and clustering at a later confirmatory freeze; retain null results and demonstrate scope beyond this feasibility sample |

Do not select a next arm because it is expected to produce favorable factual scores. Do not invent a post-output numeric acceptance threshold for this wave. A future coverage or precision threshold must be justified and recorded before the future inference it governs. The exact remaining measurement work is the 96 human response reviews, explicit handling of disputed units, and 24 new control reviews before any matched-control generation. The native eos/eog issue requires a versioned prospective compatibility treatment before reuse as certified boundary evidence; it does not require rerunning saved outputs.

## Identification and publication limits

C1−C0 and C3−C0 estimate total added packages. C1−N_style would compare style information with explicit absence-of-style information at matched length/wrapper. C3−N_history would compare residence history with unrelated coherent dialogue at matched length/format; relevance, historical facts and temporal information would still differ. Neither matched comparison has response data in this wave. H does not independently manipulate historical relevance, temporal validity and presentation. F contains unrelated facts; S includes wording/context changes. Persona Fidelity is unmeasured, and the prompt describes the target speaker rather than guaranteeing role simulation.

Existing work overlaps persona sensitivity, memory admission/presentation, and real-user conversational behavior. The [updated novelty assessment](P1_novelty_assessment.md) gives verified comparisons, testable extensions and falsifiers. A high CROSS_TURN rate, a factorial layout, model size or a longer experiment is not itself a contribution. Structural-versus-semantic separation becomes useful evidence only if independently supported and changes a scientifically meaningful interpretation.

PLOS ONE emphasizes rigorous methods, supported conclusions and a justified original or replication question; it considers negative and null results. The journal does not guarantee acceptance of this pilot, nor impose our proposed exact model-arm count. Its [official publication criteria](https://journals.plos.org/plosone/s/criteria-for-publication) support prioritizing valid measurement and appropriate sample/analysis design over favorable effects. Wave 1 is exploratory; no significance, causal mechanism, general factual accuracy or submission-readiness claim is made.
